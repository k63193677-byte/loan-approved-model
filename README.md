Loan Approval Prediction

About the Project

This project predicts whether a loan application is likely to be approved based on applicant data using Python and Machine Learning.

Project Files

- "maincode.py" — Python source code for the project.
- "loan_data_1.csv" — Dataset used for prediction.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

Objective

The main objective of this project is to analyze applicant data and predict loan approval using machine learning techniques.

How to Run

1. Install Python on your computer.
2. Install the required libraries.
3. Keep the Python file and dataset in the same folder.
4. Run "maincode.py".
